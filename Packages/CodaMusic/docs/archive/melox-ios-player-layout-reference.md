# MeloX iOS 播放详情页：上下部布局准备

读取日期：2026-10-26。参考 MeloX `main` 的提交 `9c2f87b57b54ddbab76a4a53736f4840719a0947`，并对照用户提供的竖屏截图。本次只整理布局，不修改播放器代码。

## 来源

源码目录：https://github.com/youshen2/MeloX/tree/9c2f87b57b54ddbab76a4a53736f4840719a0947/MeloX/Features/Player/NowPlaying

- `NowPlayingView.swift`：竖屏容器、安全区、收起手柄与底部覆盖层。
- `NowPlayingSongHeader.swift`：封面、标题、歌手、右侧操作。
- `NowPlayingSongActions.swift`：收藏与更多菜单。
- `NowPlayingBottomControls.swift`：底部各行高度、间隔与显示隐藏。
- `NowPlayingControls.swift`：进度、音质、播放、音量、底部入口。

以下源码尺寸单位均为 pt。截图仅用于辨认顺序和视觉比例，不能将图片像素直接作为 SwiftUI 尺寸。

## 上部

MeloX 竖屏容器左右内边距 32，底部另加安全区内边距 3。顶部手柄区域高 34；胶囊宽 60、高 5、距区域顶部 8，白色透明度 0.52。

歌词页顶部使用 `NowPlayingSongHeader(usesReferenceLayout: true)`：

- 横向排列：封面 → 两行元数据 → 更多菜单，间距 12。
- 封面 72 × 72，圆角 12。
- 标题 `.title3.weight(.semibold)`，歌手 `.title3`，两行间距 2；均单行截断。
- 歌手白色透明度 0.64，多歌手以 ` & ` 连接。
- 元数据占剩余宽度。标题行还可能出现心动模式、一起听徽标。
- 该布局关闭独立收藏按钮；更多按钮 40 × 40，圆形背景白色透明度 0.15。

截图与当前 MeloX 源码不同：截图右侧依次是添加歌单、红心、更多，无明显圆形按钮底。截图更适合作为本项目入口顺序的参考。

## 下部

MeloX 将控制区覆盖在内容底部，而非挤压歌词容器。底部总高度 341，其中上方歌词语言工具区 62，核心控制区 279。工具区按钮靠左；无翻译/罗马音时仍保留其高度。

核心控制区从上到下：

| 区域 | 高度 / 间隔 | 内容 |
| --- | --- | --- |
| 进度 | 52 | 滑条；下一行左已播时间、右负号剩余时间，中间覆盖音质入口 |
| 间隔 | 19 | 固定空白 |
| 播放控制 | 82 | iPhone 标准布局为上一首、播放/暂停、下一首，穿插 Spacer |
| 间隔 | 31 | 固定空白 |
| 音量 | 42 | 小音量图标、滑条、大音量图标，横向间距 10 |
| 间隔 | 3 | 固定空白 |
| 页面入口 | 50 | 歌词、悬浮歌词、队列；此行内部左右再缩进 32 |

标准播放按钮触控容器直径 64；上一首/下一首图标字号 34，播放/暂停 48。进度时间为 `.caption2.monospacedDigit()`，白色透明度 0.5。进度滑条隐藏滑块。音量图标透明度 0.62，滑条高 32。

MeloX 的 tablet 播放控件才包含两侧随机/循环：随机 → 上一首 → 播放 → 下一首 → 循环；整体高 52，按钮容器 44，图标分别 16 / 24 / 30 / 24 / 16。不能把这一套尺寸误认为截图的 iPhone 五按钮尺寸。

截图下部：进度与居中 Hi-Res → 五个播放按钮 → 音量 → 左侧设备名称，右侧评论、队列、歌词。此入口构成也与当前 MeloX iPhone 标准布局不同。

## 本项目对应位置与后续调整范围

主文件：`Sources/Kumone/Features/Player/NowPlayingView.swift`。

| 区域 | 现有实现 | 后续调整点 |
| --- | --- | --- |
| 竖屏整体 | `portraitLayout(size:)` | 当前窄屏左右 24、宽屏 48，内容宽上限 680；顶部 padding 手机 48 / iPad 64。先统一手柄、信息栏与安全区的关系 |
| 顶部封面 | `portraitLayout(size:)` | 手机 52、iPad 72；与 MeloX 竖屏参考 72 存在差异，按截图比例和可用宽度调整 |
| 信息与操作 | `NowPlayingTrackInfoRow` | 已具备添加歌单、喜欢、更多顺序。手机标题 body 粗体、次行 footnote，需评估文字与按钮的空间分配 |
| 下部整体 | `portraitPlaybackControls(width:controlScale:)` | 当前按屏高缩放留白；进度后 35×scale、播放后 38×scale、音量后 12×scale，需形成明确的行高和间隔规范 |
| 进度音质 | `NowPlayingScrubber` | 当前高 44，滑条区域 24、文字间隔 5；已有剩余时间和居中音质，可沿用行为，仅调整布局 |
| 五键播放 | `iPadTransportControls(width:)` | 竖屏手机也复用它，五列均分；当前两侧字号 17、前后 28。调整图标比例时同时检查中央播放按钮 |
| 音量 | `iPadVolumeControl` | 当前间距 12、行高至少 44，使用系统音量滑条 |
| 最底栏 | `portraitUtilityBar` | 已是左设备、右评论/队列/歌词；保留当前功能映射，调整间距与选中底色 |

建议以用户截图确定控件顺序，以 MeloX 源码借鉴容器和尺寸组织；优先修改顶部信息密度与底部各行留白，不直接移植 MeloX 的页面切换入口或设置分支。继续保持项目唯一播放器界面，设备与方向仅做响应式适配。

后续实现需检查：长歌名/多歌手的截断、顶部三个按钮的触控空间、较矮手机的控制区高度、iPad 宽度限制、歌词与控制覆盖层的稳定关系、音质入口和进度拖动的命中区域。按项目约定在 UI 代码修改完成后构建并覆盖安装可用真机及已启动模拟器，安装后不启动应用或自动化 Runner。
