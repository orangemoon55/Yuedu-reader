# Lyricify Lyrics Helper

Source: https://github.com/WXRIW/Lyricify-Lyrics-Helper

Reference commit: `77e7acbcabb14502924fa1d74fa9d8a3a928c59f`

Kumone adapts the QQMusic, Kugou and LRCLIB request protocols and KRC decoding algorithm into native Swift in `AlternativeLyricsAPI.swift`. This is a modified implementation, not the upstream .NET library. KRC timing is converted to the existing YRC lyric model. Providers requiring account credentials are not included.
