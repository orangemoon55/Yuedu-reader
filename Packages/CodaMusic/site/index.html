多平台合一

所有曲库，
一个入口。

网易云音乐、QQ 音乐、酷狗音乐和汽水音乐，在同一个界面里搜索、收藏和播放。扫码或导入凭证登录，可保存多个账号，在设置中随时切换。

  • 网易云音乐
  • QQ 音乐
  • 酷狗音乐
  • 汽水音乐

各平台可用功能不同，以应用内为准。

沉浸歌词 · 流动背景

歌词与背景，
随音乐一起流动。

支持逐行同步与逐字同步歌词，可显示翻译，日语歌曲支持罗马音。歌词来源在多个平台间自动优选，也可按歌曲手动切换。背景从专辑封面取色，跟着节拍和旋律起伏律动。

  • 逐行同步
  • 逐字同步
  • 歌词翻译
  • 罗马音
  • 多平台优选
  • 封面取色
  • 随节拍律动

下载安装

从 GitHub Releases 获取最新版本。

macOS

macOS 15 或更高版本

  1. 下载 Coda-x.y.z.zip 并解压到“应用程序”。
  2. 首次打开被拦截时，前往 系统设置 → 隐私与安全性，点击 仍要打开。
下载 Mac 版

iPhone 与 iPad

iOS / iPadOS 16 或更高版本

  1. 下载 Coda-iOS-x.y.z.ipa。
  2. 用 AltStore 或 SideStore 以你自己的 Apple ID 签名安装。
