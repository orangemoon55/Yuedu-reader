# Coda 原生分类搜索（Readcc 本地适配）

- 原生搜索页保留 Coda SearchView、MusicTrackPanel、播放器及底栏；搜索栏固定在结果滚动容器之外。
- 单曲支持全源聚合与网易云音乐、QQ音乐、酷狗音乐、汽水音乐单平台筛选，结果组和行尾均标注来源。不是 Readcc 书源聚合。
- 歌手、专辑、歌单继续保留原生当前平台类别；全源或非当前平台仅提供单曲，避免裸实体 ID 跨平台误路由。
- 聚合请求显式指定平台，不为搜索循环切换全局账号。单源失败不抹掉其他来源；分页偏移独立、可重试失败来源。
- 非当前平台的原生播放、喜欢、歌单、下载和详情菜单整体禁用。用户明确点“切换到…”，经原生 MusicAccountManager 正规激活后再使用该平台结果；切换会停止当前播放并重置队列，界面明确提示，不自动播放。
- DEBUG 本地 UI 夹具明确标为非网络结果，全部行禁止播放；不能据夹具断言真实接口/登录/播放成功。
- 新 Swift 测试放在 CodaCoreTests，并原字节镜像到宿主同步测试目录；media51 选择集包含15项模型/传输/操作策略测试及4项搜索 UI 测试，iPad和iPhone均选择。镜像校验在本地验证脚本中执行。
- 保留阅读、删除影视、无重叠宿主底栏、无旧音乐横条、首页原生设置与独立同步、设置精简政策。
- 尚未原生编译/真实账号/联网搜索/实播验收。旧 parent3b1e47e 云包不含本新增搜索功能。
